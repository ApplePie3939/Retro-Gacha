# 古町レトロ・ガチャウォーク

新潟市の古町・本町エリアを歩きながら、新しい店舗と出会うための回遊促進アプリです。ガチャで行き先を決め、店舗のQRコードを読み取ってコインを集め、クーポンと交換する体験を試せます。

> このリポジトリはプロトタイプです。実在する店舗の情報を使用していますが、アカウントやクーポンを含む機能はデモ用です。

## 公開デモを試す

**[古町レトロ・ガチャウォークを開く](https://applepie3939.github.io/Retro-Gacha/)**

1. 新しいユーザーを登録します。
2. ガチャを回して、ランダムに選ばれた店舗を確認します。
3. 「コインを獲得する」から店舗のQRコードを読み取ります。
4. 1店舗につき1回、100コインを獲得できます。
5. 貯めたコインをクーポンと交換します。

公開デモでは、アカウント、コイン、訪問履歴、所持クーポンをブラウザの `localStorage` に保存します。データは別の端末やブラウザには共有されません。

## 2つの動作モード

| | GitHub Pages版 | ローカルPHP版 |
|---|---|---|
| 用途 | インストール不要の体験用デモ | 開発・動作確認 |
| データ保存先 | ブラウザの `localStorage` | SQLite (`static/db/gacha.db`) |
| アカウントの共有 | 同じブラウザ内のみ | 同じサーバーの利用者間 |
| バックエンド | ブラウザ内のデモAPI | PHP API |
| 起動方法 | 公開URLへアクセス | PHPのローカルサーバーを起動 |

画面と基本的な操作は共通です。GitHub Pagesへのデプロイ時だけ、設定ファイルをデモAPI用に差し替えています。

## ローカルで起動する

### 必要なもの

- PHP 7.4以上
- PDO SQLite拡張
- QRコード画像を再生成する場合はインターネット接続

リポジトリを取得した後、次のコマンドを実行します。

```bash
cd static
php init_db.php
php -S 0.0.0.0:8080
```

ブラウザで [http://localhost:8080](http://localhost:8080) を開いてください。サーバーを停止するには、起動したターミナルで `Ctrl+C` を押します。

> `php init_db.php` は既存の `db/gacha.db` を削除し、サンプルデータを入れ直します。保存済みのユーザーや履歴も消えるため注意してください。

WindowsでXAMPPを `C:\xampp` にインストールしている場合は、`static/start_server.bat` をダブルクリックして、必要に応じたDB初期化とサーバー起動を行うこともできます。

より詳しい環境構築、API、データベースの情報は [ローカルPHP版 開発ガイド](static/README.md) を参照してください。

## 主な機能

- ユーザー登録、ログイン、ログアウト
- ランダムな店舗を表示するガチャ演出
- 店舗情報とGoogle マップへのリンク
- カメラまたは画像ファイルからのQRコード読み取り
- 店舗訪問によるコイン獲得
- クーポン一覧、交換、所持クーポンの確認

## プロジェクト構成

```text
.
├── .github/workflows/       # GitHub Pagesのデプロイ設定
├── deploy/
│   └── pages-config.js      # Pages版をデモAPIに切り替える設定
├── static/
│   ├── api/                 # PHP API
│   ├── db/                  # SQLiteデータベース
│   ├── images/              # 店舗・ガチャ・QRコード画像
│   ├── includes/            # PHP共通処理
│   ├── js/                  # PHP／Pages共通のAPIクライアント
│   ├── pages/               # ログイン、ガチャ、QR、クーポン画面
│   ├── index.html           # トップページ

│   └── start_server.bat     # XAMPP向けWindows起動スクリプト
└── tests/
    └── demo-api.test.cjs    # Pages版デモAPIのテスト
```

## テスト

Node.jsが利用できる環境で、リポジトリのルートから実行します。

```bash
node --test tests/demo-api.test.cjs
```

登録・ログイン、QR報酬、クーポン交換、ガチャ、PHP APIアダプターの基本動作を確認します。

## 利用上の注意

- デモ用の実装であり、公開サービスとして必要なセキュリティ対策は行っていません。
- GitHub Pages版では入力したパスワードもブラウザ内に保存されます。普段使用しているパスワードは入力しないでください。
- ローカルPHP版でもパスワードを平文で保存します。信頼できないネットワークやインターネットへ公開しないでください。
- QRコードのカメラ読み取りには、ブラウザからのカメラ利用許可が必要です。
- DB初期化時のQRコード生成には外部のQR Code APIを使用します。通信に失敗してもDBは作成されますが、QR画像は生成されない場合があります。
- GitHub Pages版のデータを消す場合は、ブラウザのサイトデータから `applepie3939.github.io` のローカルストレージを削除してください。
